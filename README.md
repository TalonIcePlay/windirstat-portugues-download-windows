# WinDirStat em Português para Windows

**WinDirStat em português para Windows** é uma ferramenta gratuita e de código aberto para **analisar o espaço em disco**, descobrir arquivos grandes e entender rapidamente o que está ocupando espaço no seu computador.

Este projeto tem como objetivo facilitar o uso do WinDirStat por usuários de língua portuguesa, mantendo a funcionalidade original da ferramenta e disponibilizando uma versão localizada para Windows.

## O que é o WinDirStat?

O WinDirStat é um **analisador de espaço em disco para Windows** que mostra como o armazenamento do computador está sendo utilizado.

A ferramenta verifica discos e pastas e apresenta os resultados de forma visual. Com o mapa de árvore (Treemap), é possível identificar rapidamente quais arquivos e diretórios estão ocupando mais espaço.

Se o seu **disco está cheio** e você não sabe o motivo, o WinDirStat pode ajudar a encontrar arquivos grandes, pastas que ocupam muito espaço e outros dados que podem estar consumindo o armazenamento.

## Por que usar um analisador de disco?

Com o tempo, arquivos temporários, downloads, vídeos, imagens, instaladores e outros dados podem ocupar uma grande quantidade de espaço.

O Windows mostra algumas informações sobre o armazenamento, mas uma ferramenta dedicada permite visualizar o conteúdo do disco com muito mais detalhes.

O WinDirStat organiza os dados de forma visual para que você possa encontrar rapidamente onde está o maior consumo de espaço.

## Como analisar o espaço em disco no Windows?

1. Baixe a versão mais recente na página de [Releases](../../releases).
2. Instale o WinDirStat ou utilize a versão portátil, quando disponível.
3. Abra o programa.
4. Selecione a unidade ou pasta que deseja analisar.
5. Aguarde o término da análise.
6. Utilize a lista de arquivos e o Treemap para encontrar o que está ocupando mais espaço.

Depois da análise, você poderá identificar rapidamente os maiores arquivos e diretórios do computador.

## Como encontrar arquivos grandes?

Depois que o WinDirStat terminar de analisar o disco, observe o tamanho dos arquivos e diretórios apresentados.

O Treemap facilita essa tarefa porque os arquivos que ocupam mais espaço aparecem representados por áreas maiores.

Você pode utilizar essas informações para encontrar vídeos, arquivos de instalação, backups, downloads ou outros dados que estejam ocupando espaço desnecessariamente.

Antes de excluir qualquer arquivo, verifique se ele é realmente desnecessário e se não é utilizado pelo Windows ou por outro programa.

## Como liberar espaço no disco?

Primeiro, utilize o WinDirStat para descobrir quais arquivos e pastas estão ocupando mais espaço.

Depois de identificar os arquivos desnecessários, você pode:

* Excluir arquivos temporários
* Remover downloads antigos
* Apagar arquivos grandes que não são mais necessários
* Mover arquivos pessoais para outro disco
* Arquivar documentos e mídias
* Desinstalar programas que não utiliza

Tenha cuidado ao remover arquivos do sistema ou arquivos cujo propósito você não conhece.
